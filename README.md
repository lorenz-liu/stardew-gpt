# StardewGPT

StardewGPT is the in-game ChatGPT-like AI assistant for Stardew Valley, built with the latest foundational model and a contextual knowledge base of the game and your game stats. 

## Quick Start

**Important: use a real API key from Groq in `config.json`!**

```json
{
  "ApiEndpoint": "https://api.groq.com/openai/v1/chat/completions",
  "ApiKey": "REPLACE_WITH_YOUR_GROQ_API", <- Replace this 
  "Model": "openai/gpt-oss-120b",
  "MaxTokens": 500,
  "Temperature": 0.8,
  "OpenChatKey": "K" <- Press K to open chat in game
}
```

Get an API key from [Groq](https://console.groq.com/keys); it's easy and free.
