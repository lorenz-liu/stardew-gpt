The **Tent Kit** is a [craftable item](/Crafting "Crafting") that allows the player to construct a tent to sleep in. It can only be used outdoors and is consumed after use. Three Tent Kits are found in a box in the [Ginger Island jungle](/Ginger_Island#Island_East "Ginger Island"), and one Tent Kit is the first prize obtained from the [Trout Derby](/Trout_Derby "Trout Derby") festival. If a player has already used the [Golden Joja Parrot](/Golden_Walnut#Golden_Joja_Parrot "Golden Walnut"), then [Professor Snail](/Professor_Snail "Professor Snail") will give one Tent Kit as a reward for donating the [Mummified Bat](/Mummified_Bat "Mummified Bat") to the [Island Field Office](/Island_Field_Office "Island Field Office").

## Usage

The player deploys the Tent Kit outdoors by selecting the lower left corner of a 3x2 area. If there is not enough space, the player attempts to use the Tent Kit indoors (e.g. in a mine), or the next day is a [festival](/Festivals "Festivals"), then an error message is shown.[[1]](#cite_note-tenterror-1) Otherwise, the Tent Kit deploys, and the player can use the tent just like the bed in the [farmhouse](/Farmhouse "Farmhouse"). Upon using the tent, the game is [saved](/Saves "Saves") and the player wakes up at 6am the next day in the same location, the tent itself having disappeared. In [Multiplayer](/Multiplayer "Multiplayer"), multiple people can use the tent at once.

Tent Kits placed outside that are not used will disappear the next day. Tent Kits will not work if there is a [festival](/Festivals "Festivals") occurring at the map the next day.

## Bundles

Tent Kit is not used in any [bundles](/Bundles "Bundles").

## Tailoring

Tent Kit is not used in any [tailoring](/Tailoring "Tailoring"). It can be used in [dyeing](/Dyeing "Dyeing"), serving as an orange dye at the dye pots located in [Emily](/Emily "Emily")'s and [Haley](/Haley "Haley")'s house, [2 Willow Lane](/2_Willow_Lane "2 Willow Lane"). It can also be used as a brown dye when used in the spool of the [Sewing Machine](/Sewing_Machine "Sewing Machine") with a dyeable clothing item in the feed.

## Quests

Tent Kit is not used in any [quests](/Quests "Quests").
