# Fruits

Below is a list of **Fruits** from the game, where to obtain them and how much they sell for when processed into [Jelly](/Jellies_and_Pickles "Jellies and Pickles") using the [Preserves Jar](/Preserves_Jar "Preserves Jar"), into [Wine](/Wine "Wine") using the [Keg](/Keg "Keg"), or into [Dried Fruit](/Dried_Fruit "Dried Fruit") using the [Dehydrator](/Dehydrator "Dehydrator"). Note that **five** matching Fruits are required to make one Dried Fruit.

Whether or not fruit benefits from the +10% [Tiller](/Skills#Farming "Skills") profession price bonus depends upon whether or not the specific fruit was obtained by foraging, although [the details](#Tiller_Profession_Details) can become complex.

## Tiller Profession Details

Internally, the game tracks whether fruit came from a foraging or non-foraging source, and uses this internal information to determine whether or not the fruit should get the +10% [Tiller](/Skills#Farming "Skills") profession bonus when sold.[[1]](#cite_note-tiller-1)

Sources that are considered to be foraging are:

* Wild-grown fruit that randomly spawns throughout Stardew Valley, as detailed at [Foraged Items](/Foraging#Foraged_Items "Foraging") and [Spawning](/Foraging#Spawning "Foraging")
* Fruit grown from any of the four varieties of [Wild Seeds](/Crafting#Seeds "Crafting")
* All fruit found in [the Farm Cave](/The_Cave "The Cave") -- including [Fruit Tree fruit](/Fruit_Trees "Fruit Trees") that otherwise is not considered to be foraged

All other sources are considered to be non-foraging, including (but not limited to):

* Fruit grown from standard seeds (*e.g.,* [Grapes](/Grape "Grape") from [Grape Starter](/Grape_Starter "Grape Starter"))
* Fruit collected from trees
* Fruit sent in the mail as a gift
* Fruit purchased from the [Oasis](/Oasis "Oasis")
* [Blackberries](/Blackberry "Blackberry") and [Salmonberries](/Salmonberry "Salmonberry") harvested from bushes

If the player has both foraged and non-foraged fruit of the same quality, stacking the items together always results in non-foraged fruit: the Tiller bonus will apply to the entire stack of fruit.[[2]](#cite_note-stacks-2)

## References

1. [↑](#cite_ref-tiller_1-0) The tiller bonus does not apply to fruit where the `isSpawnedObject` flag is set, see code in `Object::getPriceAfterMultipliers`. This flag is added to wild foraged items in `GameLocation::dropObject` and `GameLocation:spawnObjects`; to crops grown from wild seeds in `Crop::newDay`; and, to Farm Cave fruit in `FarmCave::dayUpdate`. Other sources do not get the flag, including notably berries from bushes in `Bush::shake`.
2. [↑](#cite_ref-stacks_2-0) The code in `Object:addToStack` was changed in v1.4 to ensure `isSpawnedObject` is set to false whenever two mixed stacks are combined, *i.e.,* that the Tiller bonus applies if either stack originally had it. Note that this code change will not retroactively fix data in games started pre-v1.4, where the Tiller bonus could be lost depending upon how stacks were combined.

* [1.5](/Version_History#1.5 "Version History"): Iridium quality is now possible when using [Deluxe Fertilizer](/Deluxe_Fertilizer "Deluxe Fertilizer").
* [1.6](/Version_History#1.6 "Version History"): Added [Powdermelon](/Powdermelon "Powdermelon") Fruit. Fruits can now be processed into [Dried Fruit](/Dried_Fruit "Dried Fruit").
