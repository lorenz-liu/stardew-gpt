The **Cookout Kit** is a [craftable item](/Crafting "Crafting") that can be used to create a small cooking fire used for [Cooking](/Cooking "Cooking") outside of the player's [Farmhouse](/Farmhouse "Farmhouse"). Once placed, it can be destroyed using an [axe](/Axes "Axes"), [hoe](/Hoes "Hoes"), or [pickaxe](/Pickaxes "Pickaxes"). Any Cookout Kits left overnight will disappear the next day.

Two Cookout Kits are the reward for completing the ![Bundle Green.png](/mediawiki/images/thumb/b/b3/Bundle_Green.png/24px-Bundle_Green.png) [Wild Medicine Bundle](/Remixed_Bundles#Wild_Medicine_Bundle "Remixed Bundles") in the [Crafts Room (Remixed)](/Remixed_Bundles#Crafts_Room "Remixed Bundles"). If a player has already used the [Golden Joja Parrot](/Golden_Walnut#Golden_Joja_Parrot "Golden Walnut"), then [Professor Snail](/Professor_Snail "Professor Snail") will give one Cookout Kit as a reward for donating the [Mummified Frog](/Mummified_Frog "Mummified Frog") to the [Island Field Office](/Island_Field_Office "Island Field Office").
