# Weight

**Weight** [![Weight.png](/mediawiki/images/thumb/6/6f/Weight.png/24px-Weight.png)](/File:Weight.png) is a statistic that affects how far an enemy will be knocked back when attacked by [the player](/The_Player "The Player") with a [weapon](/Weapons "Weapons").

Each weapon type has a default weight: [Daggers](/Weapons#Dagger "Weapons") have a weight of 5, [swords](/Weapons#Sword "Weapons") 10, and [clubs](/Weapons#Club "Weapons") 15. Some weapons have a weight modifier, which is added to or subtracted from the default weight.[[1]](#cite_note-defaultWeight-1) [Forging](/Forge#Weapon_forging "Forge") a weapon with [Amethysts](/Amethyst "Amethyst") will add +10 per amethyst to the weight.

[Amethyst Rings](/Amethyst_Ring "Amethyst Ring") and [innate enchantments](/Forge#Innate_enchantments "Forge") affect the weight multiplicatively: the multiplier starts out as 1.0. Each Amethyst Ring adds 0.1 to the multiplier, while a "-X Weight" innate enchantment will subtract X/10 from the multiplier. The actual weight value is then the weapon's weight times this multiplier.[[2]](#cite_note-buffMultiplier-2)

This means 2 Amethyst rings increase the amount of knockback by 1.2x, while a maximum-level innate enchantment (-5 Weight) will halve the knockback amount.
