**Qi Gems** are obtained by completing [challenges](/Quests#List_of_Mr._Qi.27s_Special_Orders "Quests") in [Mr. Qi](/Mr._Qi "Mr. Qi")'s [walnut room](/Qi%27s_Walnut_Room "Qi's Walnut Room") on [Ginger Island](/Ginger_Island "Ginger Island"), and used to buy rewards in the same room. They can also be received from selling [Golden Walnuts](/Golden_Walnut "Golden Walnut") and can be dropped from monsters in the ["dangerous"](/The_Mines#Shrine_of_Challenge "The Mines") versions of [the Mines](/The_Mines "The Mines") and [Skull Cavern](/Skull_Cavern "Skull Cavern"). [Stick Bugs](/Stick_Bug "Stick Bug") in the Dangerous Mines are guaranteed to drop a Qi Gem when slain, with a 50% chance of dropping an extra one. The amount of Qi Gems that a player has is displayed directly underneath [the Player](/The_Player "The Player")'s name in the skills tab.

## Tips

Two easy ways to convert Qi Gems into [gold](/Gold "Gold") are:

* Buying [Hoppers](/Hopper "Hopper") and deconstructing them using [deconstructors](/Deconstructor "Deconstructor") into [radioactive bars](/Radioactive_Bar "Radioactive Bar") which sell for data-sort-value="3000">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)3,000g each (data-sort-value="4500">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)4,500g with the [Blacksmith profession](/Mining#Mining_Skill "Mining")). This method is more profitable, but takes more time and requires deconstructors. Using this method, each Qi Gem is worth data-sort-value="300">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)300g (data-sort-value="450">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)450g with the Blacksmith profession).
* Buying [Qi Seasoning](/Qi_Seasoning "Qi Seasoning") which sell for data-sort-value="200">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)200g each. Using this method, each Qi Gem is worth data-sort-value="200">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)200g.

## Bugs

* Because the on-screen gem count display contains only 3 digits, having 1000 or more Qi Gems causes the display to show only the last 3 digits.
