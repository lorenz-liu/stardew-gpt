An **Error Item** is any item whose internal ID doesn't exist in [the game's item data](/Modding:Items "Modding:Items"). Error items have no associated item data and thus default to purchase/sell prices of data-sort-value="0">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)0g, descriptions reading "*???*", and a placeholder 🛇 sprite.

There are no known ways to produce an Error Item in the latest versions of the base game. However, they can occur due to mods.

## History

* [1.2.26](/Version_History#1.2.26 "Version History"): You can no longer find an Error Item with a bread sprite in [The Saloon](/The_Stardrop_Saloon "The Stardrop Saloon")'s shop and the [garbage can](/Garbage_Can "Garbage Can") outside the Saloon.
* [1.5](/Version_History#1.5 "Version History"): The [item spawn cheat](/Secrets#Item_Spawn_Cheat "Secrets") now ignores invalid item IDs, instead of producing Error Items.
* [1.6](/Version_History#1.6 "Version History"): Error items now display a placeholder 🛇 sprite, instead of whatever sprite matches their index position in the spritesheet. They also no longer cause crashes when interacting with them in some case.
