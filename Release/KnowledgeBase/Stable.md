The **Stable** is a [farm building](/Carpenter%27s_Shop#Farm_Buildings "Carpenter's Shop") purchasable from [Robin](/Robin "Robin") at the [Carpenter's Shop](/Carpenter%27s_Shop "Carpenter's Shop"). It takes two days to build. When complete, it allows the player to obtain a [horse](/Animals#Horse "Animals"), which is included with the stable. The horse will be found in the stable at the start of each day.

After the stable is built, the player is able to name the horse the first time it is ridden.

A farm can normally have only one stable, but in [multiplayer](/Multiplayer "Multiplayer") games, each player can build their own stable.

* [1.1](/Version_History#1.1 "Version History"): Demolishing the stable now also removes the horse from the game.
