# Dark Shrine of Memory

[![Dark Shrine of Memory.png](/mediawiki/images/thumb/f/ff/Dark_Shrine_of_Memory.png/120px-Dark_Shrine_of_Memory.png)](/File:Dark_Shrine_of_Memory.png)

The **Dark Shrine of Memory** is an altar found in the [Witch's Hut](/Witch%27s_Hut "Witch's Hut"). It can be accessed after completing the [Goblin Problem](/Quests#Goblin_Problem "Quests") quest. The player can offer data-sort-value="30000">![Gold.png](/mediawiki/images/thumb/1/10/Gold.png/18px-Gold.png)30,000g to erase all divorced spouses' memories, making it seem like they had never been married. It also erases [Krobus](/Krobus "Krobus")' memory if he is an ex-roommate. This effect takes place immediately after using the shrine.

Talking to the divorced spouses right after wiping their memories will result in this dialogue:

|  |  |
| --- | --- |
| “ | “You're the new farmer, aren't you? You seem... no. I'm sure we've never met.” |

Erasing an NPC's memory will not allow the player to see any previously seen Heart Events again.
