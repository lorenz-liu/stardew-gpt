**Tropical Curry** is a [cooked dish](/Cooking "Cooking"). It is prepared using either the kitchen inside an upgraded [farmhouse](/Farmhouse "Farmhouse") or a [Cookout Kit](/Cookout_Kit "Cookout Kit"). It can be purchased from [Leo](/Leo "Leo")'s [shop](/Desert_Festival#Villager_Shops "Desert Festival") during the [Desert Festival](/Desert_Festival "Desert Festival") for data-sort-value="30">![Calico Egg.png](/mediawiki/images/thumb/d/da/Calico_Egg.png/24px-Calico_Egg.png) 30 [Calico Eggs](/Calico_Egg "Calico Egg").

**Note:** this recipe is [profitable](/Cooking#Profitable_Recipes "Cooking") - it will result in profit when using the lowest quality ingredients.

## Tailoring

Tropical Curry is used in the spool of a [Sewing Machine](/Sewing_Machine "Sewing Machine") to create the [Tropical Sunrise Shirt](/Tailoring "Tailoring"). [![Tropical Sunrise Shirt.png](/mediawiki/images/thumb/9/9c/Tropical_Sunrise_Shirt.png/24px-Tropical_Sunrise_Shirt.png)](/File:Tropical_Sunrise_Shirt.png) It can be used in [dyeing](/Dyeing "Dyeing"), serving as an orange dye at the dye pots, located in [Emily](/Emily "Emily")'s and [Haley](/Haley "Haley")'s house, [2 Willow Lane](/2_Willow_Lane "2 Willow Lane").
