The **Strawberry** is a [fruit](/Fruits "Fruits") [crop](/Crops "Crops") that grows from [Strawberry Seeds](/Strawberry_Seeds "Strawberry Seeds") after 8 days.

## Stages

When harvested, each Strawberry plant gives 1 Strawberry every 4 days, with a 2% chance for more Strawberries.

## Number of Harvests

Preparing land by tilling, fertilizing, and watering before the [Egg Festival](/Egg_Festival "Egg Festival") can help ensure maximum growth of seeds planted after the festival ends at 10pm. The following table shows the maximum number of harvests possible when planting the night of the Egg Festival, and the day after.

| Modifier | Number of Harvests | |
| --- | --- | --- |
| Spring 13 | Spring 14 |
| None | 2 | 2 |
| 10% | 3 | 2 |
| 20% | 3 | 3 |
| 25% | 3 | 3 |
| 33% | 3 | 3 |
| 35% | 3 | 3 |
| 43% | 3 | 3 |

## Bundles

Strawberry is not used in any [bundles](/Bundles "Bundles").

## Recipes

Strawberry is not used in any recipes.

## Tailoring

Strawberry can be used in the spool of the [Sewing Machine](/2_Willow_Lane#Sewing_Machine "2 Willow Lane") to create the dyeable [Farmer Pants](/Tailoring#Pants "Tailoring"). [![Farmer Pants.png](/mediawiki/images/thumb/7/78/Farmer_Pants.png/36px-Farmer_Pants.png)](/File:Farmer_Pants.png) It can also be used as a red dye in the dye pots, located at [Emily](/Emily "Emily")'s and [Haley](/Haley "Haley")'s house, [2 Willow Lane](/2_Willow_Lane "2 Willow Lane").

## Quests

Strawberry is not used in any [quests](/Quests "Quests").

## Trivia

* It is possible to get three harvests from strawberry plants during Spring of year 1. This requires using [Speed-Gro](/Speed-Gro "Speed-Gro") and planting on Spring 13, and the easiest way to do this is to complete the [spring crops bundle](/Bundles#Spring_Crops_Bundle "Bundles"); this requires planting [cauliflower](/Cauliflower "Cauliflower") on Spring 1 as well as visiting the [Community Center](/Community_Center "Community Center") after the [Egg Festival](/Egg_Festival "Egg Festival") and before planting the strawberries.
